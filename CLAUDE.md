# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Projet

**Douce Patte** : projet en 4 phases visant à donner à un client une présence sur le web (site vitrine avec formulaire de contact), puis un espace d'administration pour gérer ses leads, un blog et des assistants IA (MCP, RAG, agent de qualification des leads).

## Arborescence

```
test-douce-patte/
├── .claude/
│   └── rules/
│       └── git-conventions.md  # Conventions de nommage des branches et des commits
├── CLAUDE.md                   # Guidance pour Claude Code (ce fichier)
└── README.md                   # Feuille de route du projet en 4 phases
```

## Mise à jour de ce fichier

Ce fichier est mis à jour régulièrement au fil de l'évolution du projet : l'arborescence et toute information pertinente (commandes, architecture, conventions) y sont ajoutées au fur et à mesure.
